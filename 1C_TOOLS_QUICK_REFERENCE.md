# Памятка по инструментам 1С в OpenCode

## Быстрый доступ к инструментам

### MCP сервер 1c-metadata
```bash
# Поиск по метаданным
/search_metadata query="текст" metadataType="Catalogs"

# Структура конфигурации
/get_metadata_structure

# Поиск объекта по имени
/find_object_by_name objectName="ИмяОбъекта"
```

### Инструмент 1c-syntax-checker
```bash
# Проверка синтаксиса XML файла
1c-syntax-checker filePath="путь/к/файлу.xml"
```

### MCP сервер 1c-help
```bash
# Поиск по справке
/search_1c_help query="СтрНайти" category="функция"

# Синтаксис конструкций
/get_1c_syntax construct="Если"

# Примеры кода
/get_1c_examples topic="работа с датами"

# Онлайн-справка
/search_web_help query="запрос"
```

## Порядок работы с изменениями

1. **АНАЛИЗ**: `search_metadata` → `find_object_by_name`
2. **ИЗМЕНЕНИЕ**: Редактирование кода
3. **ПРОВЕРКА**: `1c-syntax-checker` → `get_1c_syntax`
4. **ЗАВЕРШЕНИЕ**: Проверка чек-листа

## Типы метаданных для поиска
- `Catalogs` - Справочники
- `Documents` - Документы  
- `AccumulationRegisters` - Регистры накопления
- `InformationRegisters` - Регистры сведений
- `CommonModules` - Общие модули
- `DataProcessors` - Обработки
- `Reports` - Отчеты
- `Enums` - Перечисления

## Категории справки
- `функция` - Встроенные функции
- `процедура` - Процедуры платформы
- `конструктор` - Конструкторы объектов
- `метод` - Методы коллекций
- `все` - Все категории
