# MCP Инструменты OpenCode

## Обзор

В проекте используются 3 MCP (Model Context Protocol) инструмента для интеграции с 1С:Предприятие и обеспечения современной среды разработки.

## Инструменты

### 1. [1c-metadata](./1c-metadata/) - Анализатор метаданных
Поиск, анализ и навигация по метаданным конфигурации 1С.

### 2. [1c-help](./1c-help/) - Справка по 1С
Доступ к справочной информации 1С, примерам кода и синтаксису языка.

### 3. [1c-syntax-checker](./1c-syntax-checker/) - Проверка синтаксиса
Проверка синтаксиса BSL файлов через LSP сервер.

## Интеграция

Все MCP инструменты интегрированы в `opencode.json` и доступны через:

- **Правую панель OpenCode** - визуальный интерфейс
- **Командную строку** - прямые вызовы инструментов
- **API** - программное использование

## Конфигурация

Основные настройки MCP инструментов находятся в:
- `opencode.json` - регистрация и включение инструментов
- `.opencode/mcp/*/` - исходный код инструментов
- `docs/lsp/` - настройка LSP сервера для синтаксической проверки

## Использование

### Перед началом работы
1. Убедитесь, что LSP сервер запущен (для 1c-syntax-checker)
2. Проверьте конфигурацию в `opencode.json`
3. Изучите документацию по конкретному инструменту

### Рекомендуемый порядок работы
1. **Анализ** - используйте `1c-metadata` для изучения структуры
2. **Изучение** - используйте `1c-help` для понимания конструкций
3. **Разработка** - пишите код с учетом существующих паттернов
4. **Проверка** - используйте `1c-syntax-checker` для валидации

## Требования

- Node.js 18+
- Docker (для LSP сервера)
- Доступ к GitHub (для скачивания BSL Language Server)

## Поддержка

При возникновении проблем:
1. Проверьте логи в консоли OpenCode
2. Убедитесь, что все зависимости установлены
3. Проверьте настройки в `opencode.json`
4. Обратитесь к документации конкретного инструмента
