# Инструменты 1c-metadata

## search_metadata

### Назначение
Поиск по метаданным конфигурации 1С с возможностью фильтрации по типу.

### Параметры
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `query` | string | Да | Текст для поиска в метаданных |
| `metadataType` | string | Нет | Тип метаданных для фильтрации |

### Типы метаданных
- `Catalogs` - Справочники
- `Documents` - Документы
- `AccumulationRegisters` - Регистры накопления
- `InformationRegisters` - Регистры сведений
- `CommonModules` - Общие модули
- `DataProcessors` - Обработки
- `Reports` - Отчеты
- `Enums` - Перечисления
- `ChartsOfCharacteristicTypes` - Планы видов характеристик

### Примеры запросов
```bash
# Поиск всех объектов с "Номенклатура"
/search_metadata query="Номенклатура"

# Поиск только в справочниках
/search_metadata query="Партнеры" metadataType="Catalogs"

# Поиск модулей алсав
/search_metadata query="алсав_" metadataType="CommonModules"
```

### Формат ответа
```json
{
  "query": "Номенклатура",
  "metadataType": "Catalogs",
  "found": 3,
  "results": [
    {
      "path": "/ext_alsav/Catalogs/Номенклатура/Номенклатура.xml",
      "type": "Catalogs",
      "matches": [
        {
          "line": 1,
          "content": "<Metadata name=\"Номенклатура\"..."
        }
      ]
    }
  ]
}
```

## get_metadata_structure

### Назначение
Получение полной структуры метаданных конфигурации.

### Параметры
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `path` | string | Нет | Путь к директории с метаданными (по умолчанию текущая) |

### Примеры запросов
```bash
# Полная структура конфигурации
/get_metadata_structure

# Структура конкретной директории
/get_metadata_structure path="ext_alsav"
```

### Формат ответа
```json
{
  "Catalogs": {
    "type": "Catalogs",
    "objects": [
      {
        "name": "Номенклатура",
        "path": "/ext_alsav/Catalogs/Номенклатура",
        "hasXml": true
      }
    ]
  }
}
```

## find_object_by_name

### Назначение
Поиск объектов метаданных по точному имени или его части.

### Параметры
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `objectName` | string | Да | Имя объекта для поиска |

### Примеры запросов
```bash
# Точный поиск
/find_object_by_name objectName="Номенклатура"

# Поиск по части имени
/find_object_by_name objectName="алсав_"

# Поиск документов
/find_object_by_name objectName="Реализация"
```

### Формат ответа
```json
{
  "objectName": "Номенклатура",
  "found": 2,
  "results": [
    {
      "path": "/ext_alsav/Catalogs/Номенклатура",
      "type": "directory",
      "metadataType": "Catalogs"
    },
    {
      "path": "/ext_alsav/Catalogs/Номенклатура/Номенклатура.xml",
      "type": "file",
      "metadataType": "Catalogs"
    }
  ]
}
```

## Особенности использования

### Поиск в содержимом
Инструменты ищут текст в содержимом XML файлов, что позволяет:
- Находить объекты по реквизитам
- Искать использования в формах и модулях
- Определять связи между объектами

### Работа с расширениями
Поиск выполняется по всем директориям:
- `base/` - базовая конфигурация
- `ext_alsav/` - основное расширение
- `ext_b24/` - расширение Битрикс24

### Ограничения
- Максимальное количество совпадений - 10 на файл
- Поиск нечувствителен к регистру
- Поддерживаются только XML файлы метаданных
