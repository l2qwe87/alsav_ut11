# 1c-metadata - Анализатор метаданных

## Обзор

MCP сервер для поиска, анализа и навигации по метаданным конфигурации 1С:Предприятие.

## Функциональность

### Поиск и анализ
- Поиск объектов по имени и содержимому
- Анализ связей между объектами
- Получение структуры конфигурации
- Поиск зависимостей перед изменениями

### Поддерживаемые типы метаданных
- **Справочники** (Catalogs)
- **Документы** (Documents) 
- **Регистры** (AccumulationRegisters, InformationRegisters)
- **Общие модули** (CommonModules)
- **Обработки** (DataProcessors)
- **Отчеты** (Reports)
- **Перечисления** (Enums)
- **Планы видов характеристик** (ChartsOfCharacteristicTypes)
- **Бизнес-процессы** (BusinessProcesses)
- **Задачи** (Tasks)
- **Роли** (Roles)
- **Подсистемы** (Subsystems)
- **Общие формы** (CommonForms)
- **Общие картинки** (CommonPictures)
- **Константы** (Constants)
- **Функциональные опции** (FunctionalOptions)
- **Определяемые типы** (DefinedTypes)
- **Группы команд** (CommandGroups)
- **Общие команды** (CommonCommands)
- **Элементы стиля** (StyleItems)
- **Языки** (Languages)

## Инструменты

### search_metadata
Поиск по метаданным конфигурации.

**Параметры:**
- `query` (строка) - текст для поиска
- `metadataType` (опционально) - тип метаданных для фильтрации

**Возвращает:** Найденные объекты с путями и совпадениями.

### get_metadata_structure
Получение структуры метаданных конфигурации.

**Параметры:**
- `path` (опционально) - путь к директории для анализа

**Возвращает:** Древовидную структуру метаданных.

### find_object_by_name
Поиск объекта метаданных по имени.

**Параметры:**
- `objectName` (строка) - имя объекта для поиска

**Возвращает:** Найденные объекты с информацией о типе и расположении.

## Использование

### Перед изменением объекта
```bash
/search_metadata query="Номенклатура" metadataType="Catalogs"
/find_object_by_name objectName="Номенклатура"
```

### Анализ зависимостей
```bash
/search_metadata query="ДокументРеализацияТоваровУслуг"
/get_metadata_structure
```

### Поиск использования
```bash
/search_metadata query="алсав_ВыгрузкаCsvJson"
```

## Рекомендации по использованию

### Обязательные проверки
- **Перед изменением метаданных** - всегда используйте `search_metadata` для анализа связей
- **Перед удалением** - проверьте использование объекта через `find_object_by_name`
- **При рефакторинге** - используйте `get_metadata_structure` для понимания контекста

### Оптимизация поиска
- Используйте `metadataType` для сужения области поиска
- Применяйте конкретные имена объектов для точного поиска
- Анализируйте результаты для выявления скрытых зависимостей

## Интеграция с рабочим процессом

### В IDE
Инструмент доступен через правую панель OpenCode и позволяет:
- Быстро находить нужные объекты
- Анализировать влияние изменений
- Навигировать по структуре конфигурации

### В CI/CD
Используется для автоматической проверки:
- Целостности связей между объектами
- Корректности реорганизации метаданных
- Соответствия архитектурным принципам
