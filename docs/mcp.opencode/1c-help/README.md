# 1c-help - Справка по 1С

## Обзор

MCP сервер для доступа к справочной информации 1С:Предприятие, примерам кода и синтаксису языка BSL.

## Функциональность

### Справочная информация
- Поиск по встроенной справке 1С
- Доступ к онлайн-документации
- Получение синтаксиса конструкций языка
- Примеры кода для типовых задач

### Поддерживаемые категории
- **Функции** - встроенные функции платформы
- **Процедуры** - процедуры платформы и языка
- **Конструкторы** - конструкторы объектов
- **Методы** - методы объектов
- **Все** - поиск по всем категориям

## Инструменты

### search_1c_help
Поиск по встроенной справке 1С.

**Параметры:**
- `query` (строка) - текст для поиска
- `category` (опционально) - категория поиска (функция, процедура, конструктор, метод, все)

**Возвращает:** Найденную справочную информацию с описанием и примерами.

### get_1c_syntax
Получение синтаксиса конструкций языка 1С.

**Параметры:**
- `construct` (строка) - название конструкции языка

**Возвращает:** Синтаксис конструкции с описанием параметров.

### get_1c_examples
Получение примеров кода по теме.

**Параметры:**
- `topic` (строка) - тема для примеров кода

**Возвращает:** Примеры кода с пояснениями.

### search_web_help
Поиск по онлайн-справке 1С.

**Параметры:**
- `query` (строка) - текст для поиска в онлайн-справке

**Возвращает:** Результаты поиска из онлайн-документации.

## Использование

### Изучение синтаксиса
```bash
/get_1c_syntax construct="Если"
/get_1c_syntax construct="Для"
/get_1c_syntax construct="Пока"
```

### Поиск функций
```bash
/search_1c_help query="СтрНайти" category="функция"
/search_1c_help query="Найти" category="метод"
```

### Получение примеров
```bash
/get_1c_examples topic="работа с датами"
/get_1c_examples topic="работа со строками"
/get_1c_examples topic="запросы"
```

### Онлайн-поиск
```bash
/search_web_help query="отчеты СКД"
/search_web_help query="управляемые формы"
```

## Рекомендации по использованию

### При написании кода
1. **Проверка синтаксиса** - используйте `get_1c_syntax` для конструкций
2. **Поиск функций** - используйте `search_1c_help` для поиска нужных функций
3. **Изучение примеров** - используйте `get_1c_examples` для изучения паттернов

### При отладке
1. **Поиск ошибок** - используйте `search_1c_help` для понимания сообщений об ошибках
2. **Онлайн-документация** - используйте `search_web_help` для самой актуальной информации

### При обучении
1. **Изучение основ** - начните с `get_1c_syntax` для базовых конструкций
2. **Практика** - используйте `get_1c_examples` для реальных примеров
3. **Углубление** - используйте `search_web_help` для сложных тем

## Интеграция с рабочим процессом

### В IDE
Инструмент доступен через правую панель OpenCode и позволяет:
- Быстро находить нужные функции и процедуры
- Проверять синтаксис конструкций в реальном времени
- Изучать примеры кода без переключения контекста

### В обучении
Используется для:
- Быстрого ознакомления с синтаксисом
- Изучения лучших практик
- Понимания платформенных возможностей
