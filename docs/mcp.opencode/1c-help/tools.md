# Инструменты 1c-help

## search_1c_help

### Назначение
Поиск по встроенной справке 1С с возможностью фильтрации по категориям.

### Параметры
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `query` | string | Да | Текст для поиска в справке |
| `category` | string | Нет | Категория поиска |

### Категории поиска
- `функция` - Встроенные функции платформы
- `процедура` - Процедуры платформы и языка
- `конструктор` - Конструкторы объектов
- `метод` - Методы объектов
- `все` - Поиск по всем категориям (по умолчанию)

### Примеры запросов
```bash
# Поиск функции
/search_1c_help query="СтрНайти" category="функция"

# Поиск метода
/search_1c_help query="Найти" category="метод"

# Поиск по всем категориям
/search_1c_help query="Дата"

# Поиск конструктора
/search_1c_help query="Новый" category="конструктор"
```

### Формат ответа
```json
{
  "query": "СтрНайти",
  "category": "функция",
  "results": [
    {
      "title": "СтрНайти",
      "description": "Ищет подстроку в строке",
      "syntax": "СтрНайти(<Строка>, <ПодстрокаПоиска>)",
      "parameters": [
        {
          "name": "Строка",
          "type": "Строка",
          "description": "Строка для поиска"
        }
      ],
      "examples": [
        "Результат = СтрНайти(\"Текст\", \"ек\");"
      ]
    }
  ]
}
```

## get_1c_syntax

### Назначение
Получение синтаксиса конструкций языка 1С.

### Параметры
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `construct` | string | Да | Название конструкции языка |

### Поддерживаемые конструкции
- `Если` - Условный оператор
- `Для` - Цикл по коллекции
- `Пока` - Цикл с условием
- `Попытка` - Обработка исключений
- `Процедура` - Объявление процедуры
- `Функция` - Объявление функции
- `Новый` - Создание объекта
- `Тип` - Описание типа
- `Найти` - Поиск в коллекциях

### Примеры запросов
```bash
# Условный оператор
/get_1c_syntax construct="Если"

# Циклы
/get_1c_syntax construct="Для"
/get_1c_syntax construct="Пока"

# Обработка исключений
/get_1c_syntax construct="Попытка"

# Объявления
/get_1c_syntax construct="Процедура"
/get_1c_syntax construct="Функция"
```

### Формат ответа
```json
{
  "construct": "Если",
  "syntax": "Если <Условие> Тогда\n    // Действия\nИначеЕсли <Условие> Тогда\n    // Действия\nИначе\n    // Действия\nКонецЕсли;",
  "description": "Условный оператор для выполнения разных действий в зависимости от условия",
  "parameters": [
    {
      "name": "Условие",
      "type": "Булево",
      "description": "Логическое выражение"
    }
  ],
  "examples": [
    "Если ЗначениеЗаполнено(Контрагент) Тогда\n    Сообщить(\"Контрагент указан\");\nКонецЕсли;"
  ]
}
```

## get_1c_examples

### Назначение
Получение примеров кода по указанной теме.

### Параметры
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `topic` | string | Да | Тема для примеров кода |

### Популярные темы
- "работа с датами"
- "работа со строками"
- "работа с массивами"
- "работа с таблицами значений"
- "запросы"
- "управляемые формы"
- "работа с файлами"
- "работа с COM объектами"

### Примеры запросов
```bash
# Работа с датами
/get_1c_examples topic="работа с датами"

# Работа со строками
/get_1c_examples topic="работа со строками"

# Запросы
/get_1c_examples topic="запросы"

# Формы
/get_1c_examples topic="управляемые формы"
```

### Формат ответа
```json
{
  "topic": "работа с датами",
  "examples": [
    {
      "title": "Получение текущей даты",
      "code": "ТекущаяДата = ТекущаяДата();",
      "description": "Получает текущую дату и время"
    },
    {
      "title": "Форматирование даты",
      "code": "СтрокаДаты = Формат(Дата, \"ДФ=dd.MM.yyyy\");",
      "description": "Форматирует дату в строку"
    }
  ]
}
```

## search_web_help

### Назначение
Поиск по онлайн-справке 1С для получения самой актуальной информации.

### Параметры
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `query` | string | Да | Текст для поиска в онлайн-справке |

### Примеры запросов
```bash
# Поиск по СКД
/search_web_help query="система компоновки данных"

# Поиск по формам
/search_web_help query="управляемые формы"

# Поиск по новым возможностям
/search_web_help query="новые возможности платформы"
```

### Формат ответа
```json
{
  "query": "система компоновки данных",
  "results": [
    {
      "title": "Система компоновки данных",
      "url": "https://its.1c.ru/db/v8std#content:...",
      "description": "Описание системы компоновки данных",
      "relevance": 0.95
    }
  ]
}
```

## Особенности использования

### Контекстный поиск
Инструменты учитывают контекст поиска:
- Анализируют схожие запросы
- Предлагают релевантные результаты
- Учитывают популярность тем

### Интеграция с платформой
Доступна информация:
- О последних версиях платформы
- О новых возможностях
- Об устаревших функциях
- О лучших практиках

### Многоязычность
Поддерживается поиск:
- На русском языке
- На английском языке
- С техническими терминами
- С синонимами функций
