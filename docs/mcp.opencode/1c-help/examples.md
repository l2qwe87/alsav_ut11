# Примеры использования 1c-help

## Сценарий 1: Написание функции обработки строк

### Задача
Написать функцию для форматирования ФИО.

### Порядок действий
1. **Изучить функции работы со строками**
```bash
/search_1c_help query="СтрНайти" category="функция"
/search_1c_help query="Лев" category="функция"
/search_1c_help query="Прав" category="функция"
```

2. **Получить примеры работы со строками**
```bash
/get_1c_examples topic="работа со строками"
```

3. **Проверить синтаксис процедур**
```bash
/get_1c_syntax construct="Функция"
```

### Ожидаемый результат
- Изучены функции для работы со строками
- Получены примеры форматирования
- Проверен синтаксис объявления функций

## Рекомендации по эффективному использованию

### Стратегия поиска
1. **Начинайте с конкретного** - используйте точные названия функций
2. **Расширяйте поиск** - если не нашли, используйте общие категории
3. **Используйте синонимы** - пробуйте разные формулировки

### Комбинирование инструментов
1. **Синтаксис + Примеры** - сначала изучите синтаксис, затем примеры
2. **Функции + Конструкции** - ищите функции и проверяйте синтаксис конструкций
3. **Онлайн + Офлайн** - используйте встроенную справку и онлайн-документацию

### Практические советы
1. **Сохраняйте примеры** - создавайте коллекцию полезных примеров
2. **Изучайте параметры** - обращайте внимание на все параметры функций
3. **Тестируйте код** - всегда проверяйте примеры в реальных условиях
4. **Следуйте обновлениям** - используйте онлайн-справку для актуальной информации
