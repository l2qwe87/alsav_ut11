## Рефакторинг: вынос логики экспорта в специализированные модули

### Изменения:
- **Рефакторинг основной обработки**: Логика адресов и реквизитов вынесена в отдельные модули
  - `алсавб24_ВыгрузкаКонтрагентов_Адреса` - специализированная обработка адресов
  - `алсавб24_ВыгрузкаКонтрагентов_РеквизитыКомпании` - специализированная обработка реквизитов
- **Основная обработка**: Теперь вызывает методы из специализированных модулей
  - Упрощена структура кода, улучшена читаемость
  - Сохранена обратная совместимость API
- **Специализированные модули**:
  - `алсавб24_ВыгрузкаКонтрагентов_Адреса`: функции создания/обновления адресов, регистрации сопоставлений
  - `алсавб24_ВыгрузкаКонтрагентов_РеквизитыКомпании`: функции создания/обновления универсальных реквизитов
- **Константы типов адресов**: Добавлены в модуль адресов согласно документации Bitrix24

### Архитектурные улучшения:
- **Разделение ответственности**: Каждый модуль отвечает за свою область (адреса/реквизиты)
- **Переиспользование кода**: Специализированные модули могут использоваться другими обработками
- **Упрощение поддержки**: Изменения в логике адресов не затрагивают основную обработку

### Тестирование:
- Код проверен через 1c-syntax-checker
- Функциональность экспорта сохранена
- Все вызовы API остаются неизменными для внешних пользователей
