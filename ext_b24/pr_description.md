## Добавлена поддержка экспорта адресов контрагентов в Битрикс24

### Изменения:
- **Функция ПодготовитьПоляКонтрагента**: Добавлена обработка контактной информации типа "Адрес"
  - Экспортируются фактические адреса контрагентов (вид "ФактАдресКонтрагента")
  - Адреса передаются в поле "ADDRESS" как текстовая строка (разделены "; ")
- **Обработка номеров телефонов**: Добавлено разделение номеров, записанных через запятую
  - Номера телефонов разделяются по запятой и экспортируются как отдельные записи PHONE
  - Удаляются лишние пробелы вокруг номеров
- **Обработка адресов email**: Добавлено разделение email-адресов, записанных через запятую
  - Email-адреса разделяются по запятой и экспортируются как отдельные записи EMAIL
  - Удаляются лишние пробелы вокруг адресов
- **Исправление API вызовов**: Добавлен параметр params с REGISTER_SONET_EVENT: "N"
  - Предотвращает регистрацию событий в живой ленте Bitrix24 при создании/обновлении компаний
  - Исправлены имена параметров (id, fields) согласно документации API
- **Исправление доступа к полям API**: Изменено обращение к полю ID реквизитов
  - API возвращает Соответствие, поэтому используется .Получить("ID")
  - Поле ID в верхнем регистре согласно документации Bitrix24
- **Форматирование кода**: Убраны лишние пробелы, стандартизированы отступы
- **Проверка синтаксиса**: Код проверен на соответствие правилам 1С

### Тестирование:
- Код проверен через 1c-syntax-checker
- Изменения не нарушают существующую функциональность экспорта контрагентов
