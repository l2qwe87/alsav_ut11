# Синхронизация 1С и Битрикс24

## Текущее состояние

### Системы
- **1С: Управление торговлей (УТ)** - основная система учета
- **Битрикс24 (Б24)** - CRM система

### Соответствие сущностей
- **Б24 Смарт-процесс** ↔ **1С Партнёр**
- **Б24 Компания** ↔ **1С Контрагент**

### Что уже сделано
1. **API модули для работы с Б24**
   - Реализован модуль `алсавб24_Http` для HTTP запросов
   - Реализован модуль `алсавб24_Json` для работы с JSON
   - Реализован модуль `алсавб24_api_CRM_Компании` для работы с компаниями Б24

2. **Регистр сопоставления**
   - Создан регистр сведений `алсавб24_СопоставлениеОбъектовБ24` для хранения связей
   - Структура регистра:
     - **ID** - идентификатор сущности в Б24 (измерение)
     - **Объект1С** - ссылка на объект 1С (Партнеры или Контрагенты) (ресурс)
     - **TITLE** - наименование сущности в Б24 (ресурс)
     - **ПохожийПартнер1-3** - возможные дубли для ручного сопоставления (ресурсы)

3. **Обработки выгрузки**
   - Реализована обработка `алсавб24_ВыгрузкаПартнеров` для выгрузки партнеров в смарт-процессы Б24
   - Реализована обработка `алсавб24_ВыгрузкаКонтрагентов` для выгрузки контрагентов в компании Б24

### Текущая архитектура

#### Регистр алсавб24_СопоставлениеОбъектовБ24
Регистр используется для хранения связей между объектами 1С и сущностями Б24:
- **Измерение ID** - уникальный идентификатор сущности в Б24
- **Ресурсы** - ссылки на объекты 1С и метаданные сущностей Б24
- Поддерживает хранение нескольких возможных соответствий для ручного выбора

#### Процесс выгрузки
1. **Проверка сопоставления** - поиск в регистре по ссылке на объект 1С
2. **Поиск в Б24** - поиск сущности по ORIGIN_ID (GUID объекта 1С)
3. **Подготовка данных** - формирование полей для API Б24
4. **Создание/обновление** - вызов соответствующих методов API
5. **Регистрация связи** - сохранение сопоставления в регистр

### Особенности реализации
- **ORIGIN_ID** используется GUID объекта 1С для уникальной идентификации
- **ORIGINATOR_ID** установлен как "1С8 УТ11" для идентификации источника
- Поддерживается выгрузка контактной информации (телефоны, email, веб-сайты)
- Для контрагентов дополнительно выгружаются юридические реквизиты (ИНН, КПП)

### Ограничения
- Синхронизация контактов и контактных лиц не реализуется
- Используется принцип "ведущая система 1С" - изменения только из 1С в Б24
- Отсутствует двусторонняя синхронизация
