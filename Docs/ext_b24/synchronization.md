# Синхронизация 1С и Битрикс24

## Текущее состояние

### Системы
- **1С: Управление торговлей (УТ)** - основная система учета
- **Битрикс24 (Б24)** - CRM система

### Соответствие сущностей
- **Б24 Компания** ↔ **1С Партнёр**
- **Б24 Контакт (контрагент)** ↔ **1С Контрагент** 
- **Б24 Контакт (контактное лицо)** ↔ **1С Контактное лицо**

### Что уже сделано
1. **Загрузка в Б24 из файлов**
   - Выполнена загрузка контактов в Битрикс24 из файлов
   - **Проблема:** отсутствует связь с сущностями 1С
   - **Проблема:** нет идентификации и определения типа (контрагент или контактное лицо)

2. **Выгрузка из 1С в Б24**
   - Реализована выгрузка Партнёров из 1С в Битрикс24

### Текущая проблема
**Отсутствие связи между сущностями:**
- Созданные в Б24 сущности (после загрузки из файлов) не связаны с сущностями 1С
- Нет механизма идентификации и сопоставления
- Дублирование данных при выгрузке из 1С

## Планы по решению

### Задачи
1. **Идентификация сущностей Б24**
   - Определить тип контакта (контрагент или контактное лицо)
   - Найти соответствующие партнёров в 1С

2. **Создание связей**
   - Установить соответствие между сущностями Б24 и 1С
   - Предотвратить дублирование при дальнейшей выгрузке

3. **Механизм сопоставления**
   - Поиск по ИНН, названию, email, телефону
   - Ручное сопоставление для неоднозначных случаев
   - Автоматическое создание связей для точных совпадений

### Ожидаемый результат
- Единая база клиентов без дублирования
- Чёткая идентификация типов контактов
- Надёжная синхронизация между системами
