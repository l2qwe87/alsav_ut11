# 1C Help MCP Server

MCP сервер для поиска по справке 1С:Предприятие и получения примеров кода.

## Возможности

- **Поиск по справке**: Поиск функций, процедур и конструкций языка 1С
- **Синтаксис конструкций**: Получение синтаксиса языковых конструкций
- **Онлайн-справка**: Поиск в онлайн-ресурсах документации 1С
- **Примеры кода**: Готовые примеры кода для различных задач

## Инструменты

### search_1c_help
Ищет информацию в базе знаний 1С.

Параметры:
- `query` (string): Текст для поиска
- `category` (string, опционально): Категория поиска (функция, процедура, конструктор, метод, все)

### get_1c_syntax
Возвращает синтаксис конструкции языка 1С.

Параметры:
- `construct` (string): Название конструкции (Если, Для, Пока, и т.д.)

### search_web_help
Выполняет поиск в онлайн-справке 1С.

Параметры:
- `query` (string): Текст для поиска

### get_1c_examples
Возвращает примеры кода 1С по указанной теме.

Параметры:
- `topic` (string): Тема для примеров

Доступные темы:
- работа с датами
- работа со строками
- работа с массивами
- работа с таблицей значений
- запросы
- структуры

## Установка

1. Установите зависимости:
```bash
cd .opencode/mcp/1c-help
npm install
```

2. MCP сервер уже настроен в `opencode.json`

## Использование

После настройки OpenCode сможет использовать следующие инструменты:

```
/search_1c_help - Найти информацию в справке 1С
/get_1c_syntax - Получить синтаксис конструкции
/search_web_help - Поиск в онлайн-справке
/get_1c_examples - Получить примеры кода
```

## База знаний

Сервер включает встроенную базу знаний по:

- **Функциям**: СтрНайти, СтрДлина, Сумма, Макс, Мин и др.
- **Процедурам**: Сообщить, Предупреждение, Вопрос и др.
- **Конструкторам**: Новый, Новый Структура, Новый ТаблицаЗначений и др.
- **Методам**: Найти, Добавить, Удалить, Количество и др.

## Примеры использования

### Поиск функции
```
/search_1c_help query="СтрНайти" category="функция"
```

### Получение синтаксиса
```
/get_1c_syntax construct="Если"
```

### Примеры кода
```
/get_1c_examples topic="работа с датами"
```
