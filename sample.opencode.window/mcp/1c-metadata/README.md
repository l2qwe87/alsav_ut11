# 1C Metadata MCP Server

MCP сервер для поиска и анализа метаданных конфигурации 1С:Предприятие.

## Возможности

- **Поиск по метаданным**: Поиск текста в XML файлах метаданных
- **Структура конфигурации**: Получение полной структуры метаданных
- **Поиск по имени**: Поиск объектов метаданных по имени

## Инструменты

### search_metadata
Ищет текст в метаданных конфигурации 1С.

Параметры:
- `query` (string): Текст для поиска
- `metadataType` (string, опционально): Тип метаданных для фильтрации

### get_metadata_structure
Возвращает структуру метаданных конфигурации.

Параметры:
- `path` (string, опционально): Путь к директории с метаданными

### find_object_by_name
Ищет объекты метаданных по имени.

Параметры:
- `objectName` (string): Имя объекта для поиска

## Установка

1. Установите зависимости:
```bash
cd .opencode/mcp/1c-metadata
npm install
```

2. MCP сервер уже настроен в `opencode.json`

## Использование

После настройки OpenCode сможет использовать следующие инструменты:

```
/search_metadata - Найти текст в метаданных
/get_metadata_structure - Получить структуру конфигурации  
/find_object_by_name - Найти объект по имени
```

## Поддерживаемые типы метаданных

- Catalogs (Справочники)
- Documents (Документы)
- AccumulationRegisters (Регистры накопления)
- InformationRegisters (Регистры сведений)
- CommonModules (Общие модули)
- DataProcessors (Обработки)
- Reports (Отчеты)
- Enums (Перечисления)
- ChartsOfCharacteristicTypes (Виды характеристик)
- И другие типы метаданных
