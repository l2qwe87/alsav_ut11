# Структура проекта alsav_ut11

## Обзор

Проект представляет собой конфигурацию 1С:Предприятие с двумя расширениями для бизнес-логики и интеграции.

## Корневые файлы

| Файл | Описание |
|------|----------|
| `.gitignore` | Конфигурация Git - определяет файлы, которые не должны отслеживаться в системе контроля версий |
| `1C_TOOLS_QUICK_REFERENCE.md` | Краткий справочник по инструментам 1С, используемым в проекте |
| `AGENTS.md` | Документация с правилами работы с проектом, конвенциями кода и инструкциями по использованию инструментов |
| `opencode.json` | Конфигурация opencode - определяет MCP инструменты для интеграции с IDE |

## Основные директории

### `ext_alsav/` - Основное расширение

Содержит основную бизнес-логику системы:

**Подсистемы:**
- `CRMИМаркетинг/` - Управление взаимоотношениями с клиентами и маркетинг
- `Администрирование/` - Административные функции
- `Закупки/` - Управление закупками
- `Продажи/` - Управление продажами  
- `Склад/` - Складской учет

**Типы метаданных:**
- `AccumulationRegisters/` - Регистры накопления (выручка, себестоимость, остатки)
- `BusinessProcesses/` - Бизнес-процессы (задания)
- `Catalogs/` - Справочники (номенклатура, партнеры, варианты отчетов)
- `ChartsOfCharacteristicTypes/` - Планы видов характеристик
- `CommandGroups/` - Группы команд
- `CommonCommands/` - Общие команды (управление секретами, установка цен)
- `CommonForms/` - Общие формы
- `CommonPictures/` - Общие картинки
- `StyleItems/` - Элементы стиля

### `ext_b24/` - Расширение для интеграции с Битрикс24

Содержит функциональность для интеграции с CRM Битрикс24:

**Компоненты:**
- `Catalogs/Партнеры/` - Интеграция справочника партнеров
- `CommonModules/` - Модули для HTTP запросов и работы с JSON
- `DataProcessors/` - Обработки для выгрузки партнеров и API интеграции
- `InformationRegisters/` - Регистры сведений для сопоставления данных
- `Roles/` - Роли для доступа к функционалу Битрикс24

### `.opencode/` - Инструменты разработки

Содержит MCP инструменты для работы с проектом:

**Инструменты:**
- `1c-metadata/` - Поиск и анализ метаданных конфигурации
- `1c-help/` - Справка по языку 1С и примеры кода
- `1c-syntax-checker/` - Проверка синтаксиса BSL файлов через LSP сервер

## Принципы работы

### Разработка
- Все изменения метаданных должны проверяться через инструменты анализа зависимостей
- Синтаксис BSL файлов проверяется через LSP сервер
- Следование конвенциям кода, описанным в `AGENTS.md`

### Сборка
- Расширения компилируются в CFU файлы при необходимости
- Используются инструменты для анализа индексов и оптимизации

### Интеграция
- MCP инструменты обеспечивают бесшовную работу с IDE
- LSP сервер предоставляет проверку синтаксиса в реальном времени

## Дополнительная информация

- Проект использует Git для контроля версий
- Поддерживается работа с LSP сервером для 1С:Предприятие
- Интеграция с opencode обеспечивает современную среду разработки
